# F1 Prospecting Master Taxonomy & Parameter Status (August 2026)

Two things in one document:
1. **Simple breakdown**: which parameters and sectors have been used to generate
   leads in this engagement, and which haven't.
2. **Expanded taxonomy**: the sector/subsector map scaled to ~25 sectors and
   ~200 subsectors (F1-plausible industries only), each marked
   ✅ covered · 🟡 partial (thin slice inside a broader list) · ❌ not yet sourced.

Default for future runs: **50–5,000 employees**, affordability gates
(revenue ≥ $250M, or ≥ $150M raised in 24 months, or profitable with $1M+/yr
sports-sponsorship history), current F1 sponsors excluded.

### ❌ NOT USED (no list generated with these yet)
| Parameter | What it would add |
|---|---|
| Employees under 50 | Deliberately skipped — too small to activate $3.5M |
| Employees 5,001–5,999 | Uncovered sliver between bands |
| Cumulative funding ≥ $100M (looser) | Would ~double the scale-up list (Character.AI-tier near-misses) |
| Valuation-based gate (e.g. unicorns ≥ $1B) | Different cut of the startup world |
| Revenue tiers below $250M | Smaller but activation-capable brands |
| Growth-rate filters (headcount/revenue growth %) | "Rising fast" lists regardless of size today |
| IPO-window filter (listed in last 24 months) | Post-IPO awareness spenders as a standalone list |
| PE-owned filter | PE portfolio brands with exit-driven marketing pushes |
| B2B-only / B2C-only splits | Every list so far mixes both |
| Region-specific lists (Gulf-only, US-only, APAC-only) | Every list so far is global |
| Timing-signal-driven list (new CMO, rebrand, expiring sponsorship) | The highest-conversion trigger list — not yet built |
| Sponsors of OTHER sports (football, tennis, golf, sailing) | Proven sports buyers not yet in F1 — a poach list |
| Decision-maker/contact enrichment at scale | Only done for top-10 of the first report |

### Sectors never sourced at all (the standing exclusions)
Insurance & reinsurance · ride-hailing/mobility · pet care · QSR/fast-casual ·
travel retail & duty free · circular economy (waste/water) · yachting/marine ·
education. Plus assessed-and-skipped: hyperscalers (all in F1 already),
IT services (saturated + band-infeasible), tobacco (restricted), sanctioned

## The build queue this implies (priority order)
1. **Insurance mega-list** (carriers, reinsurers, specialty, insurtech) — biggest untouched sector
2. **Mobility** (ride-hailing, rental, tires, classifieds) + **Pet economy** + **QSR/coffee** — three consumer whitespaces in one wave
3. **Timing-signal list** (new CMOs, rebrands, expiring sponsorships of rival sports) and **other-sports-sponsors poach list** — the two unused high-conversion parameters
4. Remaining ❌ subsectors by sector group (education, travel retail, environment, marine, esports, fragrance, jewelry, OTAs, lending, drones)
5. Parameter variants on existing sectors: $100M funding floor, IPO-window, growth-rate, region splits
