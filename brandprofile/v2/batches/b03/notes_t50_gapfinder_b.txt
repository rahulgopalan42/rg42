NOTES t50_gapfinder_b (batch 3, 28 Nov 2026) - independent sector audit, second view (NACE Rev. 2 / ISIC divisions + LinkedIn industries)

== 1. INDUSTRIES NO BATCH 3 TASK COVERS ==
Method: walked the NACE Rev. 2 divisions (01-99, which map one-to-one to ISIC Rev. 4 divisions) and the LinkedIn industry list, and
compared each with the sector list and every task line in v2/batches/b03/tasks.md (sector t01-t53, subsidiaries u01-u08, country
k01-k30, clay, audit x01-x08). Country / subsidiary / clay / audit lines cut across industries and are not counted as covering an
industry unless the line names it. The classification lists were walked from working knowledge of their structure (no page fetched for
the code list itself); the comparison with tasks.md is from the file as read on 28 Nov 2026. t49 (GICS view) lists its own gaps in
notes_t49_gapfinder_a.txt; where both views find the same gap it is marked [also t49].
